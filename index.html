1. Types of Software

Section 4.1
System Software: Manages computer hardware & system resources.
  • Operating System (OS): Manages RAM memory, CPU processes, security, & UI.
  • Utility Programs: System maintenance (Disk Defragmenter, Anti-Virus, File Compression).
  • Device Drivers: Translates OS commands for hardware devices (GPU, printer).
Application Software: Performs end-user tasks.
  • General-Purpose: Off-the-shelf software for wide tasks (Word, Excel, Web Browsers).
  • Bespoke: Custom-built software for a specific client (ATM bank system, flight radar).
  • Open Source vs Proprietary: Public source code vs copyrighted compiled binaries.
Exam Tip: General-purpose software is cheap & instantly available, but may have unnecessary features. Bespoke software is tailored perfectly to client needs, but is expensive and takes time to develop.

2. OS & Interrupts

Section 4.1
5 OS Core Functions:
  1. User Interface (GUI vs CLI)
  2. Memory Allocation & RAM Management
  3. Multitasking & Process Scheduling
  4. Peripheral / Hardware Management
  5. File Management & Access Security
Interrupts & ISR (Interrupt Service Routine):

An interrupt is a signal requesting CPU attention.

  • Hardware Interrupts: Printer paper jam, keypress, mouse click.
  • Software Interrupts: Divide by zero error, stack overflow.
1. CPU suspends current task execution.
2. Saves register state onto the stack.
3. Executes the specific Interrupt Service Routine (ISR).
4. Restores saved registers and resumes original task.
🔄

3. Translators

Section 4.2

High-Level Languages (HLL) are human-readable (Python, Java). Low-Level Languages (Assembly, Machine Code) target CPU hardware directly.

Translator Translation Method Output
Compiler Translates whole program at once Standalone `.exe` file
Interpreter Translates line-by-line Immediate execution (stops on 1st error)
Assembler Converts mnemonics (`LDA`, `ADD`) Machine code binary
Compilers produce fast-running executable files that hide original source code.
Interpreters are ideal during software development because errors are caught immediately line-by-line.
🛠️

4. IDE Features

Section 4.2
✏️ Code Editor & Auto-Completion:
  • Code Editor: Line numbers, syntax color highlighting, auto-indentation.
  • Auto-Completion: Parameter & keyword suggestions as you type.
🐞 Debugging & Runtime Tools:
  • Syntax Checker: Highlights real-time syntax errors before compiling.
  • Debugger & Breakpoints: Pauses execution to inspect memory registers.
  • Runtime Environment: 1-click execution engine inside IDE.
A Breakpoint is a marker set on a specific line of code that pauses program execution so developers can inspect variable values stored in memory at that exact moment.
